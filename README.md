## Featured projects

### [AI Occupational Displacement Tracker](https://github.com/LikhithYedida/job-displacement-tracker) · [Live app](https://ai-job-displacement-tracker.streamlit.app/)
Tests whether AI-exposed occupations are actually shrinking, using BLS employment data for 861 occupations (2020–2025) and two independent AI-exposure research measures. A stepwise regression shows the apparent effect disappears once sector is controlled for. Includes a 3-year forecast, a career-pivot matcher and a workforce risk simulator with PDF export.
`Python` `pandas` `statsmodels` `SciPy` `Plotly` `Streamlit` `sentence-transformers`

### [AutoPulse](https://github.com/LikhithYedida/autopulse) · [Live app](https://autopulse-3oik.onrender.com/)
Turns a VIN into an evidence-grounded vehicle safety report from NHTSA complaints, recalls, crash ratings and emerging-issue signals. Includes explainable entity resolution and an AI analyst that never treats missing evidence as zero.
`Python` `FastAPI` `PostgreSQL` `RapidFuzz` `Anthropic API` `Render`

### [CrisisOps](https://crisisops-web-607779483839.us-central1.run.app/) · Live app
Live U.S. disaster monitoring that ranks every affected county into five priority tiers using National Weather Service alerts, population exposure, disaster history and CDC social vulnerability.
`Google Cloud Run` `NWS API` `FEMA` `CDC SVI` `Geospatial analysis`

### [Healthcare Analytics Command Center](https://github.com/LikhithYedida/healthcare-analytics-platform)
An end-to-end Azure lakehouse: Data Factory ingestion into a Bronze → Silver → Gold Databricks pipeline with built-in data-quality validation, feeding a six-page Tableau command center across utilization, claims ($14.6M tracked), readmissions and provider performance.
`Azure Data Factory` `ADLS Gen2` `Databricks` `PySpark` `Delta Lake` `Tableau`

### [Consumer Complaint Risk & Response Intelligence](https://github.com/LikhithYedida/banking-risk-intelligence)
50,000 CFPB consumer complaints ingested with Python into PostgreSQL, modeled in dbt into governed risk marts with reconciliation tests, enriched with NLP topic modeling and sentiment, and reported in a four-page Power BI risk dashboard with a composite company risk score.
`Python` `PostgreSQL` `dbt` `scikit-learn` `NLP` `Power BI` `DAX`
